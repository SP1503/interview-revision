
### Important Notes:
- Creating thread using runnable is always preferred as we can extends som other classes.
- Start method will create a new thread and execute that task. Simply calling run() directly with execute the task in the current thread only.
### Code

```Java

Class Client{
	
	private static void main(String args[]){
		
		Runnable task = new NumberPrinter1(1);
		Thread t1 = new Thread(task);
		
		// Will create a new thread and execute the task provided.
		t1.start();
		
		// Using Thread class
		Thread task2 = new NumberPrinter2(1);
		
		// Creating new thread and execute the task using that thread
		task2.start();
	}
}

Class NumberPrinter1 implements Runnable{

	private int number;
	
	public NumberPrinter1(int number){
		this.number = number;
	}
	
	@Override
	public void run(){
		System.out.println("The provided number is " 
			+ this.number + " . Generated by " + Thread.currentThread.getName());
	}
}

Class NumberPrinter2 extends Thread{

	private int number;
	
	public NumberPrinter2(int number){
		this.number = number;
	}
	
	@Override
	public void run(){
		System.out.println("The provided number is " 
			+ this.number + " . Generated by " + Thread.currentThread.getName());
	}
}

```
